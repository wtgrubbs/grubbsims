Controls and Underlying Theory

The Belousov-Zhabotinsky (BZ) Reaction

The Belousov-Zhabotinsky (BZ) reaction is a classic example of non-equilibrium thermodynamics resulting in a nonlinear chemical oscillator. Mechanistically, it typically involves the oxidation of an organic compound (such as malonic acid) by a bromate solution, catalyzed by a metal ion (like cerium or ferroin). From a scientific perspective, the BZ reaction is highly interesting because it demonstrates how a complex system can spontaneously self-organize, producing striking spatial patterns like concentric target rings and rotating spiral waves from an initially uniform state. It is widely used to study chaos theory, Turing patterns, and wave mechanics in excitable media.

Mathematical Approach

Instead of numerically integrating a stiff system of partial differential equations, this application uses a 2D continuous Cellular Automata approach to model the reaction dynamics efficiently. The space is divided into a high-resolution grid where each cell represents the local concentration of three abstract chemical species (A, B, and C). The application models the reaction trajectory over time utilizing two computational phases per frame:

  • Diffusion: The state of each cell is updated by calculating the arithmetic mean of its immediate surrounding 3x3 neighborhood (the Moore neighborhood).
  • Reaction: The concentrations are updated using standard mass-action rate equations governed by parameters α, β, and γ.

Simulation Controls

  • Alpha, Beta, Gamma (α, β, γ): Adjustable kinetic constants controlling the reaction rates between the species. Modifying these within the provided limits shifts the reaction regime (e.g., changing wave thickness and frequency).
  • Playback Speed: Adjusts how fast the visualization updates. Setting this below 1.0x will slow down the visual dynamics to allow easier study of the wave mechanics. Values over 1.0x compute multiple steps per graphical frame.
  • Grid Resolution: Increases the detail of the chemical simulation. Higher resolutions create visually stunning fine details but drastically increase the initial pre-equilibration time. Changing this resets the simulation.
  • Color Palette: Re-maps the abstract chemical concentrations (A, B, C) to varying RGB color combinations for distinct visual analysis.
  • Start/Pause & Reset: Controls the evolution of the simulation. A heavy pre-equilibration phase triggers when you first start the simulation to ensure well-developed spiral waves are rendered.
  • Capture Image: Downloads the current visual state of the reactor as a high-resolution PNG image.
