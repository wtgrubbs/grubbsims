Input File Format Info

To upload data smoothly, ensure your CSV file follows these rules:

  • Column 1: X values (independent variable)
  • Column 2: Y values (dependent variable)
  • Headers (Optional): If the first row contains text, the app will automatically detect it and set them as your axis titles.
  • Scientific Notation: Supported automatically (e.g., 1.5e-3).

Regression Analysis Background

Regression Analysis is a statistical process used to estimate the relationships between a dependent variable (Y) and an independent variable (X). The goal is to find the mathematical model that best "fits" the observed data.

  • R2 (Coefficient of Determination): A measure from 0 to 1 indicating how well the model explains the variability of the data. An R2 closer to 1 implies a tighter fit.
  • Sum of Residuals Squared (SSR): The sum of the squares of the vertical distances (residuals) between each raw data point and the fitted curve.
  • Standard Error of the Estimate (Se): Represents the average distance that the observed values fall from the regression line.
