How to Use the Simulator

Purpose of the Application

This browser-based application is a fully functional Artificial Neural Network (ANN) simulator. It allows you to design a custom network architecture, train it on your own datasets, visualize the learning process in real-time, and utilize the trained model to make predictions on unseen data.

Workflow & Constraints

  • 1. Build Network: Define the number of input nodes, output nodes, hidden layers, and nodes per hidden layer. Select your desired activation functions. Click "Build Network" to instantiate the model and visualize the uninitialized architecture.
  • 2. Train & Control: Upload a Training CSV. Toggle "Normalize Inputs" to mathematically scale features between 0 and 1. Adjust Learning Rate and Epochs, then click "Train" to begin gradient descent.
    • Cancel: Instantly aborts training without saving.
    • Pause: Pauses training and automatically downloads a checkpoint_epoch_X.csv file containing current parameters.
    • Resume Checkpoint: Upload a checkpoint CSV and click "Resume Training from Checkpoint" to load state and continue execution seamless.
  • 3. Download Weights: Export weight and bias matrices as a CSV file along with a full record of training settings.
  • 4. Run Predictions: Upload a Testing CSV. If normalized, testing data is scaled using parameters from training. Click "Run & Download Predictions" to receive predicted outputs.

Formatting Your CSV Data

To ensure the application reads your data correctly, files should adhere to these guidelines:

  • Headers: You may include an optional top row for column headers (e.g., "Age, Height, Income"). The application automatically ignores non-numeric strings in the first row.
  • Training Data: Must contain at least Input Nodes + Output Nodes columns (inputs followed by targets).
  • Testing Data Flexibility: Must contain at least Input Nodes columns. If your test file includes extra columns (such as target columns), the application automatically ignores those extra columns.
  • Data Types: All non-header data must be numerical.

Underlying Theory

Biological Inspiration

Artificial Neural Networks are computing systems loosely inspired by biological neural networks. The app visualizes nodes connected by weighted edges, allowing the network to "learn" complex patterns by adjusting these connections.

Architecture Design

The network is structured in layers:

  • Input Layer: Receives numerical features.
  • Hidden Layers: Intermediate stages extracting non-linear features.
  • Output Layer: Final network prediction.

Mathematics of Forward Propagation

During forward propagation, data moves left to right calculating Z = W · A + b followed by activation functions.

Role of Activation Functions

  • Sigmoid: Squashes values between 0 and 1.
  • Tanh: Squashes values between -1 and 1.
  • ReLU: Efficient thresholding at zero for hidden layers.
  • Linear: Standard identity function for regression outputs.

Training: Cost and Backpropagation

Calculates Mean Squared Error cost and performs gradient descent backpropagation over thousands of Epochs.
